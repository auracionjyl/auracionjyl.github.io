# Reading Meta Results Reviewer

This is a static, read-only snapshot of production progress and result figures from the Reading Meta Analysis project.

- `index.html` is the reviewer landing page.
- `data/progress.json` contains aggregate progress and metric freshness.
- `data/figures.json` is the figure catalog.
- `assets/results/` contains web-optimized copies of production figures.

No raw gaze data, processed samples, or manual review records are included. Refresh the export from the analysis repository before publishing a new snapshot.
